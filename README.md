### Привет! Я Python-разработчик и системный администратор Linux (DevSecOps)

Специализируюсь на автоматизации бизнес-процессов, сборе данных любой сложности, разработке асинхронных ботов и защите серверной инфраструктуры.

#### Основной стек и направления:
- **Парсинг и автоматизация:** Python 3.12+, `httpx`, `aiohttp`, `BeautifulSoup4`, `Playwright` (JS-рендеринг), экспорт в `Excel / CSV / JSON / SQLite / PostgreSQL`.
- **Backend и боты:** `FastAPI`, `aiogram 3`, REST API интеграции, упаковка в `Docker` / `Docker Compose`.
- **Linux и безопасность (AppSec / Hardening):** администрирование Ubuntu / Debian / AlmaLinux, тюнинг SSH, `UFW / firewalld`, `Fail2Ban`, оптимизация сети (`TCP BBR`), базовый аудит уязвимостей (SSRF, SSL/TLS, заголовки безопасности).
